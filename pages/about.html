About StudentHub Portal

StudentHub is a single web application designed to simplify campus workflow for Students, Faculty, and Admin staff.

Project Objectives

  • Single platform for attendance, results, and courses
  • Digital submission for student assignments
  • Role-based dashboards for different users
  • Accessible and mobile-responsive UI design
  • Secure server-side PHP form validation & CSRF protection (Practical 7)
  • Normalized MySQL relational schema with PDO Prepared Statements (Practical 8)

Technologies Used

  • Frontend: HTML5 (Semantic Structure)
  • Styling: CSS3 (Flexbox, Grid, Media Queries)
  • Interactivity: JavaScript ES6 (DOM & Fetch API)
  • Backend Processing: PHP 8.x (POST, Regex, Sanitization)
  • Database & Storage: MySQL, phpMyAdmin, PDO Prepared Statements, CSV & JSON
