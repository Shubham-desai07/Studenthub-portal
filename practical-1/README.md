# 🎓 StudentHub Portal

A simple web-based Student Management System developed as an academic mini-project. The portal provides role-based access for **Students**, **Faculty**, and **Admin** to manage academic activities efficiently.

## 📌 Project Overview

StudentHub Portal enables users to perform academic tasks through dedicated dashboards.

- **Students** can view courses, attendance, grades, timetable, assignments, and notices.
- **Faculty** can manage courses, mark attendance, upload grades, and post assignments.
- **Admin** manages students, faculty, courses, reports, and notices. 0
